# 📊  Luxury Watch Company Airport Expansion Analytics Dashboard
**Author:** Sara Amjad | **Date:** May 2026  

> **Academic Context:**  
This project was developed as part of Unit 19: Business Intelligence under the Pearson BTEC HND in Digital Technologies (Cyber Security). The project demonstrates the design and implementation of a Business Intelligence (BI) analytics solution for a simulated luxury retail and airport business environment using Power BI and Microsoft Excel.


## 📌 Project Overview
This repository presents a Business Intelligence (BI) analytics solution developed for a simulated version of the Luxury Watch Company (LWC). The project focuses on analysing international airport passenger trends, revenue patterns, and luxury spending behaviour to support strategic airport expansion decisions.

Microsoft Excel was used for data cleaning and preprocessing, while Power BI was used to develop interactive dashboards and analytical visualisations. DAX measures and KPI indicators were implemented to support real-time insights and data-driven decision-making.

## 🧠 Core Features

- 📊 Interactive Power BI dashboards  
- ✈️ Airport passenger trend analysis  
- 💰 Revenue and luxury spending analytics  
- 📈 KPI monitoring using DAX measures  
- 🌍 Airport and country comparison visualisations  
- 🧹 Data cleaning and preprocessing using Excel  
- 🗺 Geographic map visualisations  
- 🎛 Interactive slicers and filtering  
- 📉 Business intelligence-driven decision support  

## 🔄 System Workflow

1. 📥 Aviation datasets collected and organised  
2. 🧹 Data cleaned and transformed using Excel  
3. 📊 Data imported into Power BI  
4. 🧮 DAX measures created for KPI analysis  
5. 📈 Interactive dashboards developed  
6. 🌍 Passenger and revenue trends analysed  
7. 🎯 Insights generated for expansion planning
